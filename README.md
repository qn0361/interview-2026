# interview-frontend

Заготовка для технического собеседования

## Запуск

```bash
npm install
npm run dev
```

## Задание 1. Поиск пользователей

Реализовать компонент поиска пользователей и подключить его в `src/App.tsx`.

- Поле ввода; по мере ввода запрашивать `searchUsers(query)` из `src/api.ts`.
- Показывать состояния: загрузка, ошибка, пустой результат, список результатов.
- Функция `searchUsers` отвечает с задержкой 300–1500 мс и иногда отклоняется
  с ошибкой сети — учесть это при реализации.

## Задание 2. Код-ревью

Провести ревью файла `src/UserList.tsx`: найти проблемы и предложить, как их исправить.

## Структура

```
src/api.ts       — имитация API: тип User и функция searchUsers(query).
src/App.tsx      — точка входа, сюда подключается компонент поиска.
src/UserList.tsx — компонент из другой задачи, к первому заданию не относится.
```
